A tiny Node 22 program for the make.fun bounty
[One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

`main.ts` writes exactly one emoji to `/output/entry.txt`: 🫶 heart hands.
Warmth with no face and no words — a small, open gesture of kindness a
stranger reads instantly as friendly, with no irony, no in-joke and no
intimacy to land wrong. It feels chosen for the moment rather than the
first smiley that comes to mind, while staying readable at a glance by
anyone, of any age or background. No network, no randomness, no input —
the same emoji on every run.

Run it with Node 22:

```sh
node main.ts
```
